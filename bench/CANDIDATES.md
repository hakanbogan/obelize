# Benchmark candidate corpus

A **candidate** is a repository at a pinned SHA in which the shipped
`obelize scan` reported at least one legacy finding, under an SPDX identifier,
drawn from a written-down frame;
[ADR-040](../docs/adr/ADR-040-candidate-corpus.md)
argues each rule.
A row says only that the repository exists, that the scanner found legacy usage
at that SHA, and that its licence lets this project publish about it. The cases
in [`CASES.md`](CASES.md) are drawn from this list.

## How these were chosen

- **The gate-1 frame**: the repositories in `bench/gate1/sample.yaml`, drawn by
  systematic sampling over four size bands with the development-corpus owners
  excluded, scanned in `bench/results/gate1/scan.json`. Every rejection is
  published with its reason.
- **A targeted draw** for each pack surface the frame does not exercise, because
  rules 7-10 ship on the migration guide's word
  ([ADR-008](../docs/adr/ADR-008-scanner-and-codemod-corrections.md) D6) with
  no fixture from a real repository
  ([ADR-010](../docs/adr/ADR-010-fixture-oracle-and-atomicity.md) F-4). Each
  gets a dated query, published verbatim, with one of three outcomes never
  merged: drawn and confirmed by a scan, no eligible result among those
  examined, or no hits.

A repository is **not** a candidate when it is a fork, its licence is `none` or
`NOASSERTION`, it belongs to a development-corpus owner, it exceeds the size
cap, its owner already has two rows, its SHA no longer resolves, the scanner
found nothing, or it carries the legacy SDK's own source (a case on it would
measure a migration of the library). Being archived does not disqualify: a
frozen repository's SHA and dependencies stay put.

## What the licence rule costs

Most of the frame has no licence, and an unlicensed repository cannot be quoted
([licensing rules](../docs/BENCHMARK.md#licensing-and-publication-rules)). So
**this corpus samples licensed legacy usage, not legacy usage**, and a licence
correlates with project age, tests and outside contributors. The rejection
table below shows the size of that exclusion.

## What a candidate is not

A candidate carries no pins, interpreter, install or test command, split or
ground truth; those make it a case. It records one thing more, because it
bounds `verified_success`: the `Tests` column, path evidence of any test file
at the pinned SHA, never a judgement of the tests.

## Reproducing this

`bench/candidates_collect.py draw` re-applies the rules and re-runs the
queries; it needs the `gh` CLI authenticated, `git`, and an installed
`obelize`. `bench/candidates.py` re-renders the block from
`bench/candidates.yaml` and the two scan records; `--check` fails when it is
stale. `tests/unit/test_candidates.py` recomputes the selection from the frame,
the scan records and `pack.yaml`.

**A draw is dated, not reproducible**: GitHub re-indexes continuously and ranks
code search by relevance, so the counts, queries and repositories examined are
committed, and a reader checks the draw that happened.
